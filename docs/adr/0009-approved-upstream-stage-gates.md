# 同一分集正式阶段必须以上游定稿产物交接，分集间独立推进

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 的每条分集遵循正式阶段准入：只有上游所需创作产物已经经过用户定稿，才能启动该分集的下游**正式阶段任务**及其正式产物流程；阶段 Handoff 不可将尚未定稿的讨论或草稿冒充为正式输入。各分集彼此独立推进，允许一个项目内有些分集已完成剧本并进入导演阶段，另一些仍在故事创作，也允许已具备条件的多集批量推进。非正式的自由对话探索不等于正式阶段任务。选择此规则是为了让 Agent 创作的长链路拥有明确的输入版本、可审查门禁和可回溯来源，避免自由跨阶段导致草稿依赖混乱，且不增加“预研草稿转换为正式草稿”的额外状态体系。

**考虑的选项**：B 允许上游未定稿时提前保存下游预研草稿，灵活但增加双重生命周期与转换逻辑；C 无正式阶段限制虽自由，却难以保障 Handoff 的来源一致性，因此首期采用严格正式关卡。

**适用范围与未决边界**：本决策适用于**分集已创建后**的正式阶段交接；点子与候选创意方向在分集建立前就已存在，如何审核这些前置阶段并建立首个分集的初始 Handoff，后续细化。具体阶段清单、必需产物、可选阶段、待复核状态是否阻断正式推进，以及交接载体格式仍待讨论。此前已定稿的下游版本在上游改稿后仍依第八轮规则保留、标记待复核，不会被自动重做。
