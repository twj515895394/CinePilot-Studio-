# 正式按阶段整体定稿，场次、片段和镜头支持局部编辑

**状态：accepted**
**日期：2026-10-30**

CinePilot Studio V1 以**分集的正式创作阶段**作为用户审批与向下游正式交接的边界；一个阶段可以包含一项或多项必需产物，用户确认的是当前阶段采用的具体产物版本集合。剧本场次、导演片段和镜头允许在 Vue/Electron 中单独定位、编辑，也允许 Agent 按指定范围定点修改，但局部编辑先写入该阶段的草稿产物，**不要求每个场次、片段或镜头分别设置独立审批流程**。完成阶段审查后统一发布对应阶段的已定稿版本；旧版不覆盖，下游仍依据确切定稿来源追溯。

这样既支持剧本/分镜的高频局部修改，又避免首期给大量细颗粒度内容引入互相冲突的审批状态、门禁和版本链。**不意味着所有局部修改必须触发整集重新生成**：用户可以只改一个镜头，在原阶段整体审查这次变更。具体修订存储策略、草稿自动保存间隔、字段 Schema 与 UI 审核按钮设计属于后续实现细节。

已有 [ADR-0007](./0007-approved-artifact-revision-policy.md)、[ADR-0009](./0009-approved-upstream-stage-gates.md)、[ADR-0012](./0012-field-owned-markdown-json-sqlite.md) 等仍有效；本决策补充其审查粒度。
