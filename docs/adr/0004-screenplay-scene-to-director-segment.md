# 剧本场次与导演片段独立建模，一场次可映射多个片段

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 将创意编剧输出的**剧本场次（Screenplay Scene）**和影视制作输出的**导演片段（Segment）**作为不同的创作单位。一个剧本场次可被拆分为零到多个导演片段；每个导演片段仅对应一个明确的来源场次，且二者属于同一分集。此选择允许导演对一场戏进行多片段拆解，又能对剧本改动开展定向来源追溯、为跨阶段 Handoff 保留清晰映射；相比强制场次与片段一一对应更有导演空间，相比完全多对多映射则降低了首期的归属、影响分析和编辑复杂度。

**考虑的选项**：A 强制一对一，牺牲拆片自由；C 完全多对多，允许一个导演片段合并多个源场次，但增加阶段修改、来源归因和审查的复杂度。

**范围与未决边界**：本决策仅定义场次与片段的逻辑来源关系，不决定剧本场次的划分标准、分镜的图片表达、草稿阶段未绑定源场次的容忍度、来源版本钉选方式或场景/地点资产如何关联；一个导演片段跨多个剧本场次的需求未来再评估。
