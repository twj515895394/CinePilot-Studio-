# 上游定稿更新后标记关联下游待复核，不自动重做

**状态：accepted**  
**日期：2026-10-30**

当创意编剧或影视制作的上游阶段出现新的定稿版本时，CinePilot Studio 依据已有的产物版本依赖关系，识别相关下游成果并提示为「待复核 / 可能受影响」。旧版上游和既有下游产物均保留，不自动调用 Agent 重做；由用户决定继续沿用已有下游成果，或指定需要修改的内容，再通过 Agent 或 Web 编辑产生新草稿并按原有规则重新定稿。这样使影响提示可追溯、成本可控，并保持用户对创作结果的最终掌控权。

**考虑的选项**：自动重做全部下游会浪费调用成本、打断已确认成果；全自动语义级精准影响分析复杂、易误判且缺乏可验证的基准，因此首期先以明确的版本来源关系提示待复核，不要求 AI 判断每条镜头是否真实受到影响。

**边界**：本决策只确认“保留 + 标记 + 人工选择 + 不自动重做”的产品行为；多级传播规则、版本引用的记录粒度、沿用后的确认机制、待复核是否阻止下一阶段以及提示与状态的具体结构均需后续讨论。不对 Markdown、JSON、SQLite 的物理实现作出决定。
