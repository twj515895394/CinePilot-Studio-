# V1 优先本地 CLI 体系，优先采用可用的官方 Agent SDK 控制运行时

**状态：accepted**
**日期：2026-10-30**

CinePilot Studio V1 **优先本地/指定执行宿主的 Agent CLI 能力体系**，优先实现一个真实可用的 Agent 运行时，未来可扩展到其他 CLI 或直接模型 API。用户进一步明确：若同类 Agent 已提供官方 Agent SDK，应优先考虑通过 SDK 从 Python 后端发起会话、接收事件和工具调用，而不是强制以终端文本模拟 Agent。**SDK 只是调用/控制该 Agent 运行时的技术界面，不意味着必须改用直接模型 API**。如果 SDK 能力不足，可在统一 Runtime Adapter 下使用 CLI 或受支持的进程协议。

**取舍**：相比 V1 同时完整接入多个 CLI 与云端 SDK/API，先用一套运行时完成完整阶段闭环能降低成本；相比完全依赖直接模型 API，保留用户现有 CLI/Agent 工具生态与已安装技能的利用路径。官方 SDK 和 CLI 的实际身份验证、权限、Skills 自动发现、可用工具与多模态能力必须按目标版本验证，不得假定名称相似就可互换。

**未决定**：首个支持的具体 Agent 是 Codex 还是 Claude Code、具体 SDK/CLI 版本、认证与执行宿主（本地/远端）如何组织、哪些多模态能力作为首发验收项。其实现必须遵循项目隔离和独立的正式产物提交流程。
