# 分集与独立作品视为同一创作单位

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 将「分集（Episode）」作为一个项目内对应**一条独立完整短视频**的规范创作单位；先前所说的「独立作品（Work）」与分集指同一个领域对象，不再引入 `项目 → 作品 → 分集` 的额外层级，也不要求多集叙事连续。此选择与“一条视频一个完整剧本”、批量准备多集产物的主要目标一致，并能减少剧本、导演方案、分镜与提示词在两个相似容器之间重复归属。

**考虑的选项**：B「作品与分集两级」更适合单一长篇作品拆成连续集，但会增加当前不必要的层级和身份映射；C「独立作品与可选系列并存」便于未来系列化管理，但会提前引入多种内容容器。保留未来在需要时增加可选的系列/合集分组的空间，但不是本次已决定的需求。

**边界**：已确认 `项目 → 分集（独立短视频）` 的内容身份。分集内部片段、子片段、镜头的层次以及未来实际视频生成、分组合辑不属于本决策。
