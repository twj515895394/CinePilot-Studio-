# 创意点子和创意方向严格归属项目，跨项目仅复制内容

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 不设全局共享创意库，也不建设项目间创意共享、自动同步、引用关系或导入管理机制。每个创意点子及其创意方向只归属单个项目；如需在另一项目复用，由用户在管理界面通过**复制内容**按钮取得创意文本，随后粘贴给该项目 Agent 重新发散和创作，形成新的、独立的项目内容。这样选择是因为产品首要目标是项目内 Agent 创作和持久化管理，并非跨项目知识资产运营；使用简单文本复制即可覆盖已提出的复用场景，显著减少实体关系、权限和版本同步成本。

**考虑过的替代方案**：全局共享创意池提升复用效率，但削弱项目独立边界；项目内为主加共享/导入机制提供更多交互，却引入现阶段不需要的库、同步和溯源模型。用户明确拒绝这些复杂性，选择项目独立。

**边界**：复制仅复制人类可读创意内容，不隐式复制共享身份、历史版本或跨项目关联；复制按钮是 UI 交互能力，不改变项目级领域所有权。角色/场景资产、项目内分集关系及未来批量生成不在本次决策范围内。
