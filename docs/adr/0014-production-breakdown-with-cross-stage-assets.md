# 制作拆解是独立阶段，创作资产管理贯穿多个阶段

**状态：accepted**
**日期：2026-10-30**

CinePilot Studio 的影视制作系统保留独立的 **B2 制作拆解（Production Breakdown）** 正式阶段，负责将已定稿的剧本场次映射为导演片段/可选子片段，并形成本集制作资产需求及引用清单。角色、场景、服装、道具和视觉风格等**创作资产不是 B2 独占的产物，也不是必须等到 B2 才能创建的单独线性阶段**；资产管理作为贯穿 A3 故事深化到 B4 视频提示词的横向能力，允许随创作不断完善并被下游引用。选择此方案是为了让角色/场景设定能够在早期形成，同时保留分镜之前可审查的制作拆解结果。

**考虑的选项**：将资产全部在 B2 一次性完成并定稿，会过早限制故事与导演阶段的资产创作；将制作拆解并入 B3 分镜，则会模糊场次到片段的来源规划及独立交接边界。

**尚未决定**：项目资产跨分集引用、分集变体/覆写和资产版本钉选的具体行为，以及完整阶段必需字段与验收标准。不要因本决策提前把项目级资产继承机制当成已定稿。
