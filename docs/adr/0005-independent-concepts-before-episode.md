# 创意方向独立持久化，选定方向后才创建分集

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 将从创意点子发散出的「创意方向（Concept）」作为**独立的创意储备对象**，在分集立项前即可保存、审阅、修改、比较、筛选及归档。用户选定某一方向并明确决定进入独立视频开发时，才创建相应「分集（Episode）」，同时保留从分集回溯到选用方向与唯一主创意点子的能力。选择此方案，是为了避免把 Agent 大量生成的候选方向埋在对话或剧本附件中，也避免尚未决定制作的创意自动生成空分集；这是一项影响创意库身份、分集创建生命周期、UI 与跨阶段追溯的核心领域取舍。

**考虑的选项**：A「点子直接建分集，方向只作文本附件」虽然对象更少，却无法独立筛选和复用未选方向；C「先建分集，再在集内生成方向」便于单集工作台管理，却容易产生大量空分集，且不利于跨分集复用创意储备。

**未决定的范围**：创意点子和方向属于项目还是全局；一个方向能否派生多个分集及如何跨项目选用；能否跳过方向直接建分集；方向定稿和修改如何影响已经创建的分集；各状态机细节。以上需后续逐一讨论，不因本 ADR 提前视为已经批准。
