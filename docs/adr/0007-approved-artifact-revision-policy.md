# 定稿产物不可直接覆盖，后续修订必须重新产生草稿并确认

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 将各阶段经用户确认的定稿产物视为可追溯的历史版本。无论修改来自 Web UI 还是 Agent，都不能直接覆盖已有定稿，而须开启新的草稿版本，经过用户再次确认后才成为新定稿。下游内容仍保留其当时所依据的上游定稿版本与既有成果，不会在上游修订时自动删除或覆盖；这样能够同时支持 Agent 持续优化、用户回溯与阶段 Handoff。

**考虑过的替代方案**：直接覆盖会丢失历史和跨阶段来源；人工编辑可覆盖、Agent 编辑才保留版本的混合策略会造成不一致的审查和回溯语义。

**边界**：具体草稿自动保存、版本号规则、并发编辑、变更影响范围和下游重新审查/再生成政策仍未决定；此 ADR 不要求事件溯源系统或特定存储技术。
