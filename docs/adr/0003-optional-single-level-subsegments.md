# 分集片段采用可选单层子片段，镜头归属叶级单元

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 的分集按片段组织镜头：简单片段可直接包含镜头；复杂片段可选择拆成多个子片段，并由各子片段分别包含镜头。子片段最多一层，同一片段不混放直属镜头和子片段；每个镜头归属其唯一的最末级片段或子片段。选择这一结构是为了兼顾单条短视频的简洁分镜和较复杂的剧情段落编排，同时限制首期 Agent 产物、层级编辑、时序排序和阶段交接的复杂度。

**考虑的选项**：固定的「片段 → 子片段 → 镜头」会给简单片段引入空壳层级；任意深度片段递归则增加顺序、归属、版本和交互处理的复杂度。

**边界**：本决定只涉及分集内部影视片段的容器层级，不提前决定剧本场次与导演片段如何映射、分镜是否必须有图片、片段草稿是否可无镜头，以及资产/版本/时长如何存储。
