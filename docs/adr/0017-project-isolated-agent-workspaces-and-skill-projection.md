# 每个项目独立 Agent 工作区，禁止访问其他项目

**状态：accepted**
**日期：2026-10-30**

创建项目时 CinePilot Studio 必须为该项目建立独立工作区；在该项目内发起的 Agent 任务以**当前项目工作区**为工作目录。系统在受控的 Skill 注册/安装目录集中管理专业 Skill，项目可选择所需 Skill，由系统将其**链接或只读投射**到该项目的 Agent 可发现目录，让 Agent 能自然使用项目已启用的 Skill。**Agent 严禁访问本系统其他项目的目录、资料与媒体文件。** 此约束同时覆盖 Agent 的命令/文件工具、SDK/CLI 内建工具、系统提供的查询工具及其子进程，而不是只靠 Prompt 自觉遵守。

**安全边界**：设置 cwd、提示词禁止语句、UI 过滤或在同一用户权限下普通符号链接都不能单独构成严格文件隔离。必须按具体执行宿主提供真正的进程/文件系统隔离，使 Agent 仅可见本项目必要内容、工作草稿目录与获准的只读 Skill；其他项目根目录、全局数据库、凭据及 Skill 源目录不可直接暴露。若当前平台无法满足隔离要求，应阻止该运行时正式执行，而不宣称已经隔离。链接还需避免符号链接穿透和任意路径重定向；支持必要时使用只读 Skill 快照作为跨平台兼容手段。

**取舍**：所有项目共享一个不设边界的 CLI 工作区虽简单，但会造成跨项目数据串读；完全为每个项目复制独立 Skill 源仓库会增加管理成本。采用项目独立工作区与系统管理的选定 Skill 投射，同时兼顾管理便利和权限边界。

**未决定**：各平台具体沙箱/容器实现、CLI 权限映射、进程身份、媒体访问授权、文件树结构、Skill 版本与更新时机、桌面端/服务端部署方式。上述是实现细节，但不得弱化“其他项目不可访问”这一产品安全要求。
