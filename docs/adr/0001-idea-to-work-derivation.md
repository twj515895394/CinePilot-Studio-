# 创意点子与独立作品采用一对多派生，作品仅指定一个主创意来源

**状态：accepted**  
**日期：2026-10-30**

CinePilot Studio 中一个创意点子允许被深化为多部相互独立的视频作品，而每部独立作品必须有且只有一个主创意点子。选择这一关系是为了让同一灵感能够衍生不同题材或结局的短视频，同时保持作品创作链条和来源追溯清晰；它优于限制复用的严格一对一，也避免首期采用完全多对多来源合并所带来的复杂归因与编辑问题。

**已考虑的替代方案**：严格一对一会限制创意复用；完全多对多适合自由融合多个想法，但会增加归属、审核和展示成本。

**边界**：本决策约束主创意来源关系，不预先否定作品可参考其他点子；辅助引用、创意方向、分集术语以及作品容器结构另行讨论。
