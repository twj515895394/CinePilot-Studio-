# 同项目共享基础资产，分集独立指定变体

**状态：accepted**
**日期：2026-10-30**

CinePilot Studio 的角色、场景等基础创作资产归属于项目，并可在同一项目的不同分集中复用。各分集能够针对同一基础资产明确选择自己的外观、服装或状态等变体，而不直接修改项目基础定义；片段与镜头可进一步指定实际使用的资产及变体。这样既能保持角色身份与基础视觉设定的一致性，也允许同一角色在职场、科幻等不同分集中呈现不同造型。相对于所有分集仅使用统一不可覆写素材，方案 B 更灵活；相对于每集复制一套独立资产，方案 B 更便于一致性管理与来源追溯。

**边界**：用户确认的是“项目基础定义 + 分集显式变体”这一产品关系，并非要求以图片文件名或路径作为引用身份。技术上建议按资产 ID、版本 ID、变体 ID 关联，图片路径由统一业务服务解析；具体字段、媒体目录、变体允许修改哪些属性及镜头级覆盖规则在数据/交互设计中细化。
