# 第九轮 Grill：阶段推进与 Agent Handoff 的准入条件

> 日期：2026-10-30
> 状态：第九轮方案 A 已确认，已落档；第十轮见新讨论记录
> 讨论规范：[grill-with-docs](../process/grill-with-docs/SKILL.md)
> 依据：[CONTEXT.md](../../CONTEXT.md)、[ADR-0005](../adr/0005-independent-concepts-before-episode.md)、[ADR-0007](../adr/0007-approved-artifact-revision-policy.md)、[ADR-0008](../adr/0008-review-dependent-artifacts-without-auto-regeneration.md)

## 为什么现在讨论这个问题

用户希望长链路内容由 Agent 主创、用户确认，系统负责阶段之间的交接、规则校验、进度和可回溯产物，而不是依赖无限聊天上下文。第七、八轮已经确认定稿不可覆盖、上游新定稿仅提示下游复核；现在需要确认：**开始下个创作阶段时是否必须以正式定稿作为输入**。这一决定将影响 Agent Router 的启动规则、工作台阶段按钮及 Handoff 的正式来源边界。

### 场景压力测试

EP03 的故事大纲处于 v4 草稿，Agent 和用户还在讨论结尾。此时创作者说：「先帮我出一下导演镜头看看效果。」系统是否应该进入正式导演/分镜阶段并保存其产物？同时，该项目有 EP01、EP02 的剧本已定稿，准备批量推进导演阶段。

注意：不同分集之间**互不要求同步进度**；问题只针对同一分集的上游到下游交接。

## 方案

### A. 顺序正式关卡（本期推荐）

- **同一分集**只有在上游所需阶段获得用户定稿后，才能启动下游的**正式阶段任务与产物保存**；Agent Handoff 必须引用明确的上游定稿版本。
- 用户可继续通过一般对话讨论下一阶段的想法，但不把未定稿讨论直接当作正式分镜、正式镜头或提示词产物。
- 不同分集可同时处于不同阶段；已定稿的多个分集可按批次推进下一阶段。
- 上游后续再定稿，沿用第八轮的「待复核 + 人工决定」，不自动覆盖下游。
- **好处**：边界简单，避免下游产物基于不断变化的未定稿草稿产生歧义；阶段编排容易验证。
- **限制**：不能提前建立由草稿驱动的正式导演/分镜草稿。

### B. 允许预研草稿，但正式交接必须定稿

- 上游仍未定稿时，允许生成和保存标注「临时预研」的下游草稿；但不能下游定稿，也不算正式 Handoff。
- 上游定稿后，用户选择保留或重新生成临时产物，再正式推进。
- **好处**：探索灵活；**代价**：须区分预研草稿和正式阶段草稿、管理其依赖失效和转换过程。

### C. 完全自由跨阶段

- 任意阶段可随时产生正式产物，输入可来自未定稿草稿。
- **好处**：最大自由度；**代价**：削弱“确认后可追溯”的阶段语义，Agent Handoff、状态一致性和版本影响难以可靠约束。

## 建议与边界

推荐 **A** 作为本期默认规则：项目可批量处理多集，各集独立推进；同一集的正式阶段产物须引用上一阶段已定稿的输入。这直接服务用户要的可检索、可回溯和可审查，而不额外设计「临时预研」生命周期。

这里**未决定**阶段实际细分数量、每阶段必须有哪些产物、允许跳过的非关键阶段、已标记「待复核」的下游能否继续定稿、外部输入导入规则、正式 Handoff 的 JSON Schema；都需要随后单独确认。

## 第九轮正式结论（2026-10-30）

**用户明确选择方案 A（已确认）**：同一分集只有在上游所需创作阶段定稿后，才能正式进入下一阶段；不同分集可独立推进，允许已定稿的多集批量推进。一般对话中的提前讨论不能视为正式阶段任务或正式产物；不引入基于上游未定稿草稿的正式下游预研产物生命周期。

本轮已写入 [CONTEXT.md](../../CONTEXT.md) 并归档 [ADR-0009](../adr/0009-approved-upstream-stage-gates.md)。

### 注意：分集创建之前的两个创意环节

按 [ADR-0005](../adr/0005-independent-concepts-before-episode.md)，点子和创意方向可以在尚无分集时保存。因此本轮“同一分集正式阶段准入”不能错误应用到这些前置创意对象；前置创意到故事深化/分集的过渡，需要在阶段合同设计时单独澄清。

### 仍未定稿

- 六个阶段的具体必需产物、可选内容和分集创建前的正式边界。
- 通过阶段准入检查的详细规则与实现方式。
- 待复核状态是否阻断后续推进。
- Agent Handoff 的具体内容格式、上游定稿版本的收集与上下文裁剪方式。
- 影视制作阶段是否分为更多独立可定稿的子流程。
