# 第五轮 Grill：创意点子、候选创意方向与分集的建立时机

> 日期：2026-10-30
> 状态：第四轮已确认；第五轮待用户选择
> 遵循：[grill-with-docs](../process/grill-with-docs/SKILL.md)
> 已有依据：[CONTEXT.md](../../CONTEXT.md)、[ADR-0001](../adr/0001-idea-to-work-derivation.md)、[ADR-0002](../adr/0002-episode-is-independent-work.md)、[ADR-0004](../adr/0004-screenplay-scene-to-director-segment.md)

## 为什么当前讨论此问题？

前四轮已确定：
- 一个点子可以派生多个分集，每个分集一个主创意点子。
- 分集即一条完整独立短视频。
- 分集下的片段可以直接含镜头，或有一层可选子片段。
- 剧本场次与导演片段独立，来源关系为一对多。

但是原始创意编剧组有「点子发现 → 创意发散与筛选 → 故事深化 → 剧本」四步。如果不能保存尚未转为分集的候选方向，系统容易重回“只有最终剧本，丢失前面的创意尝试”的老问题。

本轮只解决：**候选创意方向是否是可管理的独立对象，以及创建分集的生命周期节点。**

## 场景压力测试

创作者输入原始点子：「拟人化狗狗替人类上班」。

Agent 一次产生五个候选方向：
1. 荒诞职场喜剧
2. 悬疑商业失窃
3. 科幻时间循环
4. 温情治愈
5. 动作冒险

用户选择其中两个继续深化，剩余三个以后可能再用。后面还会一次生成 50 个点子、从每个点子发散多种方案，批量选择 20 条分集。

系统必须回答：
- 未选择的方向保存在哪里？
- 它们是否可被查找、对比、归档、恢复？
- 一旦创建分集，该集如何回溯到候选方向和原始点子？
- 如果方向已经定稿但尚未开剧本，是否已经应该出现一个分集？

## 选项

### A：点子直接创建分集，候选方向只作为文本附件

`点子 Idea → 分集 Episode`。

好处：领域对象少，作品及文件层级简单。

限制：Agent 发散出的多个候选方向没有独立身份，否决/复用/对比只能通过文本或聊天记录找回，难以真正建设创意库。

### B：创意方向独立保存，选中方向后再创建分集（推荐）

```text
点子 Idea
 ├── 创意方向 Concept A（候选）
 ├── 创意方向 Concept B（选用）→ 分集 Episode 01
 ├── 创意方向 Concept C（选用）→ 分集 Episode 02
 └── 创意方向 Concept D（归档）
```

- 候选方向有独立身份，可保存、比较、筛选、改写、归档和恢复。
- 初始创意发散阶段无需立刻创建大量空分集。
- 用户明确选择某个方向并决定进入具体作品开发时才创建分集；此时分集有主创意点子，也可追溯选定方向。
- 未选择方向作为创意储备留存。
- 后续每集独立开发完整故事、剧本、导演方案与分镜。

**待后续澄清**：一个候选方向可否转化为多个分集；方向可否跨项目复用；分集能否从原始点子跳过方向直接创建；选中后的方向和集内故事方案如何保持版本一致。本轮不擅自决定这些细节。

### C：点子先创建分集，候选方向是分集内的多个分支

`点子 Idea → 分集 Episode → 多方向分支`。

好处：从一开始所有创作都归属分集，单作品工作台容易定位。

限制：50 个点子会产生大量尚未正式立项的空分集；一个点子同时发展两条独立视频时，早期方向先归哪一集不直观。

## 推荐 B 的原因

CinePilot Studio 面向以 Agent 为主的反复创意探索，且要求用户对话审阅、保留待选方案、批量生成多个分集。把候选方向当成独立产物，与进入制作的“分集”区分开，能保留创意尝试历史并减少空作品。它也为后续 Skill Router、阶段 handoff、创意去重和 UI 创意池保留明确入口。

**尚不是已确认设计**：本轮等待用户选项 B 或其他方案的反馈后，再把「创意方向」写入 CONTEXT.md，并在确有重大权衡时单独创建 ADR。
