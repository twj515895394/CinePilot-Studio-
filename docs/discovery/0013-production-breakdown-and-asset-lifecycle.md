# B2 制作拆解与跨阶段资产管理 — 核心流程确认

> 日期：2026-10-30
> 状态：已确认方案 A；后续转入项目内资产复用模型
> 依据：[八阶段合同](../spec/stage-contracts-and-artifact-map.md)、[ADR-0014](../adr/0014-production-breakdown-with-cross-stage-assets.md)

## 用户确认

针对「B2 应为独立的制作拆解阶段，角色、场景、服装、道具等资产在 A3–B4 之间横向管理、不必等到 B2 才创建」的方案，用户明确回答「确认」。

由此确定：**B2 的职责是剧本场次→导演片段/可选子片段的制作拆解、顺序组织和本集资产需求及使用清单**；不把 B2 变成一个强制从零创建或一次性完成所有视觉素材的统一资产关卡。B3 仍是后续分镜与镜头规划阶段，与 B2 有独立定稿和 Handoff 边界。

## 为什么采用

A3 就能确立故事角色，A4 确定场次涉及的人物和地点，B1 提出视觉风格与表演要求；强制所有资产只能到 B2 才建立会中断创作。另一方面，取消 B2 又会使剧本场次到导演片段的映射无法成为独立可审查的制作成果。

## 本次未确定

- 同一项目的角色/场景在不同分集间是否引用共同资产定义；
- 本集是否允许覆写或建立明确的外观、服装、状态变体；
- 资产的详细字段、图片上传、来源授权、使用版本钉选及更新影响的实现；
- 各阶段的验收字段与实际 JSON Schema。

这些不属于用户此次「确认」的范围。参见新的 [创作资产体系草案](../spec/creative-asset-model-and-use.md)，下一步仅对跨分集复用与变体的产品边界征求反馈。
